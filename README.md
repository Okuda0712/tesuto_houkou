# kamakura-site-v39

v39は「鎌倉市全域を通信断後も使う」ことを目的にしたオフラインパック版です。

## 初回だけオンラインで行うこと

1. アプリをHTTPSまたはPCのローカルサーバーで開く
2. 「保存」または「オフライン」を開く
3. 「鎌倉市全域を保存」を押す
4. 100%になるまで画面を閉じない
5. 保存完了後に機内モードで動作確認する

## 全域パックに保存するもの

- 鎌倉市の道路ネットワーク
- 歩行経路探索用グラフ
- 鉄道・河川・地名
- 国土地理院の指定避難所・指定緊急避難場所
- 津波・洪水・内水・高潮・土砂災害の表示用タイル
- アプリ本体
- 端末内の通行不可報告
- 最後に取得した現在地

道路は平常時にOpenStreetMapデータを取得し、IndexedDBへ保存します。
危険区域表示は鎌倉市範囲のズーム12〜14を事前保存し、オフライン時は保存済みタイルを利用します。

## 通信断後に使える機能

- PWA起動
- GPS現在地取得の試行
- 鎌倉市全域の端末内地図
- 避難所・津波避難場所
- 危険区域表示
- 通行不可報告の端末保存
- JavaScript A*による新規徒歩経路計算

## 通信断中に更新できない情報

気象警報、鉄道運行情報、避難所混雑、他端末からの新しい投稿、管理者の新しい更新など、外部から届くリアルタイム情報は通信復旧まで更新できません。

## 注意

初回の全域パック取得は外部公開データへアクセスするため通信環境が必要です。
OpenStreetMapの通常ラスタータイルを鎌倉市全域分まとめてダウンロードする方式は採用していません。背景地図は取得した道路ベクトルデータを端末内で描画します。

PC確認:
http://127.0.0.1:8039/

## スマホで開く

`SMARTPHONE_START.md` を参照してください。Windows向けに `start_mobile_wifi.bat` と `start_mobile_https.bat` を追加しています。

## 気象庁連携Push通知テスト

`JMA_PUSH_TEST.md` を参照してください。`start_jma_server.bat` で起動します。以前の `python -m http.server` ではPushサーバーが動きません。
